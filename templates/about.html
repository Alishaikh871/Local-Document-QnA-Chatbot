About The Project

Computer Science Presentation Project

AI-Powered Local Document QA System

An intelligent, offline document-processing chatbot designed to perform all operations locally — ensuring 100% data privacy, eliminating internet dependency, and completely reducing API costs.

Primary Objectives
Enhanced Privacy All processing is done locally. No sensitive data ever leaves the device or is sent to external cloud servers.
No Internet Required Fully offline operation at all times with direct local model inference, resulting in zero network latency.
Reduced Costs Eliminates the reliance on external cloud AI Chatbots, subscription costs, and third-party licensing fees.
Accurate Retrieval Supports multi-file formats and extracts context-aware responses using efficient semantic retrieval.
Technologies Used

Python & Flask

Application development and backend web framework.

Ollama & Mistral

Local LLM execution engine and core AI language model.

ChromaDB

Vector storage and fast semantic similarity searches.

Sentence Transformers

all-MiniLM-L6-v2 for lightweight, high-performance embeddings.

Document Parsers

PyPDF and Python-Docx for robust text extraction and cleaning.
